Install apps straight from GitHub Releases.

Autonomix CLI is a small terminal utility, written in Go, for installing and managing applications directly from GitHub Releases. Point it at a repository, and it finds the right package for your system, notices what’s already installed, and tells you when a new release lands. It’s for Linux users who get their apps from GitHub and would rather not check each project by hand.

What it does

  • Install from GitHub

    Add any GitHub repository URL, or just owner/repo, to track it.

  • Knows the package formats

    Recognises .deb, .rpm, .flatpak, .snap, .appimage and Arch packages.

  • Checks for updates

    Looks for new releases on GitHub and installs them. Updating several apps asks for your password once.

  • Sees what’s installed

    Detects whether an app is already on your system (dpkg, rpm, pacman, flatpak, snap) and shows the installed version.

  • A simple TUI

    Run autonomix-cli on its own for a terminal interface built with Bubble Tea.

  • JSON for scripts

    Add --json to add, list, check, update, install or remove for machine-readable output, for scripts and graphical frontends.

  • At home on Omarchy

    omarchy-autonomix puts your tracked apps and their updates in the Omarchy bar, and a post-update hook updates them whenever you run omarchy update.

  • Keeps itself current

    Once installed, Autonomix CLI tracks itself, so autonomix-cli update picks up its own new releases too.

Install

Download the package for your system from the latest release, then install it.

Debian and Ubuntu

sudo dpkg -i autonomix-cli_*.deb

Fedora and RHEL

sudo rpm -i autonomix-cli_*.rpm

Arch Linux

sudo pacman -U autonomix-cli_*.pkg.tar.zst

Keeping it updated

Autonomix CLI tracks itself once it’s installed. To add it explicitly:

autonomix-cli add https://github.com/ninepointlabs/autonomix-cli

Omarchy post-update hook

To update your Autonomix apps whenever you run omarchy update, install the hook from the repository’s contrib/omarchy folder:

install -m755 contrib/omarchy/autonomix.hook ~/.config/omarchy/hooks/post-update.d/autonomix.hook

From source

git clone https://github.com/ninepointlabs/autonomix-cli.git
cd autonomix-cli
go build

Usage

Run autonomix-cli for the TUI, or use the commands directly. <app> can be the app name, repo name, owner/repo or the repository URL.

autonomix-cli add <url>             # Track a GitHub repository (URL or owner/repo)
autonomix-cli list                  # List tracked apps and what's installed (no network)
autonomix-cli check [app...]        # Check tracked apps for updates
autonomix-cli update [-y] [app...]  # Install available updates (-y: don't ask)
autonomix-cli install <app>         # Install a tracked app that isn't installed yet
autonomix-cli remove <app>          # Stop tracking an app (does not uninstall it)
autonomix-cli about                 # Version, license, support and privacy

update only touches apps installed through the system package manager (dpkg, rpm, pacman). Set GITHUB_TOKEN (or GH_TOKEN) to raise the GitHub API rate limit from 60 to 5000 requests per hour. More, including the JSON format, is in the README.
